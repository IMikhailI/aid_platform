Проект помогает человеку создать структурированную заявку на конкретные нужды, а помощнику — выбрать заявку и поддержать её целевой покупкой. Модерация отделяет частные данные заявителя от публичной карточки помощи.

## Пользовательские сценарии

- заявитель создаёт заявку с категорией, описанием и ориентировочным бюджетом;
- помощник просматривает обезличенные заявки и выбирает подходящую;
- модератор проверяет заявителей и заявки;
- стороны отслеживают статус помощи и подтверждение получения.

## Технологии и структура

- **backend/** — Django REST API, модели, модерация и бизнес-правила;
- **frontend-v2/** — актуальный интерфейс MVP;
- **docker-compose.yml** — локальный стенд;
- **RUN.md** — расширенная инструкция и сценарии демо;
- **smoke_api.sh** и **smoke_negative_fraud.sh** — проверочные API-сценарии.

## Быстрый старт

Нужны Docker и Docker Compose. Создайте локальное окружение из безопасного шаблона и замените демонстрационные значения:

~~~bash
cp .env.example .env
docker compose up --build
~~~

После старта frontend доступен на **http://localhost:5173**, API — на **http://localhost:8000**. Дополнительные команды, сценарии демо и API-маршруты описаны в **RUN.md**.

## Границы текущего MVP

- Сертификаты помощи создаются во внутреннем mock-режиме: реальных платежей и денежной ценности у них нет.
- Верификация заявителя выполняется вручную внутри платформы; загрузки документов и интеграции с государственными системами нет.
- Не добавляйте реальные персональные данные, ключи и токены в Git.

Платформа проектируется вокруг обезличивания заявок и целевого использования помощи; интеграции с магазинами и фондами остаются отдельным будущим этапом.
